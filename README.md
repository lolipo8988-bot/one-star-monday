# One Star for Monday

A program that writes a single-line, one-star restaurant review of Monday
to `/output/entry.txt`.

The line is a genuine diner's complaint — seated on Monday morning, served
cold Sunday leftovers, charged five days, no sleep refills, and a special
that turns out to be meetings — so the joke only works for Monday.

Run it:

```sh
python3 main.py
```
